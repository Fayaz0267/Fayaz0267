### 🎥 AI Video Invigilation &nbsp;![Status](https://img.shields.io/badge/status-prototype-F59E0B?style=flat-square)

A standalone AI proctoring module designed to plug into an existing college online-exam system.

- 👁️ **Face landmarks + gaze estimation** and **secondary-device detection** with MediaPipe
- 📊 **Risk scoring (LOW → CRITICAL)** backed by event evidence
- 🧑‍🏫 **Faculty dashboard** to review sessions

> **Design principle:** the AI reports *events, confidence and evidence*; **faculty makes the final call**. No single detection is ever labeled "cheating", which keeps false positives low.
